# JTBD02 — 모의 응답지 (페르소나 12인 · 리허설용)

> 🚨 **이 문서는 실제 인터뷰 결과가 아니다.**
>
> 열두 사람 모두 실존 인물이 아니고, 아래 모든 발화는 **작성된 것**이다. 실측치처럼 적힌 숫자(진입 시간, 자막 지연 초)도 관측값이 아니다.
>
> **용도는 셋뿐이다.** ① [문항지](./JTBD01-인터뷰-문항지.md)가 실제로 작동하는지 리허설한다 ② 기록·채점·대조 시트가 응답을 담아낼 수 있는지 확인한다 ③ 우리 판단을 반박하는 응답이 들어왔을 때 분석 파이프라인이 무너지지 않는지 시험한다.
>
> **이 문서의 어떤 숫자도 AOS·DOS 재계산에 투입하지 않는다.** 실제 인터뷰 결과는 별도 문서로 작성한다.

## 이 리허설을 설계한 방식

모의 응답이 우리 Pain 리스트를 전부 확인해 주면 리허설의 의미가 없다. **분석이 반박을 흡수할 수 있는지가 확인 대상**이므로, 열두 세션 중 다섯에 의도적으로 우리 판단과 어긋나는 응답을 넣었다.

| 인물 | 시나리오 방향 |
|---|---|
| C1 · C3 · C5 · E1 · E2 | 우리 판단을 대체로 **확인** |
| **C2 · C4** | 항목 간 **순위가 역전** |
| **A1** | **매출 논거가 흔들린다** |
| **A3** | **지불 주체 판정이 뒤집힌다** |
| **N1** | 이탈 원인이 우리 가설과 **미묘하게 다르다** |
| **N2** | DOS 음수 판정이 **잘못된 비교**였다 |

## 이 세션이 남긴 것

- **C1-1 확인.** Importance 5, Satisfaction 2 모두 유지.
- **신규 대체 수단 발견 — 커뮤니티 알림 on/off 토글.** Satisfaction 재채점 대상은 아니지만, 결과 노출 회피가 별도 Job임을 시사.
- **Habit의 성격이 다르다.** 우리는 습관을 관성으로 봤는데 이 사람은 대안이 없어서 머문다. 두 경우의 처방이 다르다.
- **Q38이 문항지의 공백을 지적했다** — 커뮤니티 동시 시청이 공통 문항에 없다.

## 🔴 이 세션이 뒤집은 것 — DOS 음수 판정

- 🔴 **N2-1의 DOS 음수(−0.3)가 잘못된 비교였다.** 우리는 Satisfaction을 **4**로 매기며 "지상파 자막 방송이 실제 제공되고 본인도 불편을 느끼지 않는다"고 적었다. 그런데 **불편을 느끼지 않은 이유는 비교 대상이 없었기 때문**이고, 데모를 본 직후 본인이 "부족하다"고 답을 바꿨다.
- **Satisfaction 4 → 2~3으로 재채점.** Importance 3 → 4. 재계산하면 `AOS 0.6 → 4 × 0.5 = 2.0`, `DOS −0.3 → 3 × 0.3 = 0.9`. **최하위(25위)에서 중위권으로 올라온다.**
- 🔴 **"이미 충족됐다"는 판정은 비교 대상을 본 적 없는 사람에게 물어서 얻은 것이었다.** 이것이 이번 리허설에서 얻은 방법론적 교훈이다. **Satisfaction을 자기보고로 매길 때, 대안을 경험한 적 없는 응답자의 만족은 만족이 아니다.**
- **N2-3 확인.** T1이 로그인 화면에서 실제로 중단됐다. Importance 5, Satisfaction 1 확인.
- 🔴 **Anxiety 5가 12인 중 최대다.** 이유가 보안 불신("뉴스에서 사기당한다고 봤다")이다. 이것은 우리 제품으로 풀 수 없고 **파트너의 인증 설계**에 달려 있다. OS01이 N2-3을 '관문'으로 분류하고 파트너 협의로 보낸 판단이 맞았다.
- 🟡 **N2-g가 실행안을 확인했다.** "아들이 다 해 놓고 켜기만 하면 되면 해요." **계정 위임이 유효하다.** 이 경로가 열리면 전환 판정이 뒤집힐 가능성이 있다(Anxiety 5 → 2 예상).
- **Q38·N2-h가 새 Habit을 드러냈다** — **"부탁하기 미안함".** 이것은 습관이 아니라 관계 비용이다. 계정 위임 설계 시 "자녀가 대신 한다"는 것 자체가 저항이 될 수 있다.
