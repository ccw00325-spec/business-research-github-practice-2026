# 07_prompts

같은 작업을 여러 번 시킬 때 쓰는 지시문을 파일로 둡니다. 대화창에 매번 다시 쓰면 조건이 조금씩 달라져서 결과를 비교할 수 없습니다.

파일 하나에 프롬프트 하나, 파일명은 `무엇을하는지.md`로 씁니다. 프롬프트 본문과 함께 아래를 적습니다.

- 무엇을 입력으로 주는지 (어느 문서를 붙여 넣는지)
- 어떤 형태로 받아야 통과인지
- 지난번에 어디서 틀렸는지

## 후보

- 새 시장에 5 Forces를 적용하는 지시문
- CJM Pain Point를 AOS 채점표로 옮기는 지시문
- JTBD 응답에서 Job Statement를 뽑는 지시문
