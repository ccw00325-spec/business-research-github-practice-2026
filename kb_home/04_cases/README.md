# 04_cases

시장 하나가 폴더 하나입니다. 프레임워크 적용 결과가 아니라 **그 시장에 대해 우리가 지금 아는 것**을 모으는 곳입니다.

| 케이스 | 어디까지 왔는가 |
|---|---|
| [sports-ott-accessibility](./sports-ott-accessibility/) | 8단계 전 구간. JTBD는 모의 응답까지 |
| OTT 일반 | 3단계(KSF)까지. 케이스 폴더 없음, [사례 지도](../01_maps/moc-cases.md)에서 원문으로 |
| 온라인 커머스 | 3단계(KSF)까지. 4단계 이후로 가려면 시장 규모부터 |

케이스 폴더는 원문을 복사하지 않습니다. 원문은 루트 프레임워크 폴더에 두고, 여기에는 링크와 **결정 기록·근거**만 모읍니다. 같은 표가 두 곳에 있으면 곧 어긋납니다.
