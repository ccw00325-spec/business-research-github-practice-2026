# 스포츠 OTT 접근성

시·청각장애인이 스포츠 중계를 따라갈 수 있게 하는 접근성 레이어입니다. 이 저장소에서 4단계(시장 규모) 이후를 끌고 가는 유일한 케이스입니다.

## 한 줄 가설

접근 가능한 경기 단서가 제때 전달되지 않으면 상황 이해와 현장감이 끊기고, 반복된 실패가 흥미 저하와 시청 회피로 굳어집니다.

## 단계별 문서

전체 목록은 [사례 지도](../../01_maps/moc-cases.md#스포츠-ott-접근성-4단계-이후는-이-사례-한-줄기)에 있습니다. 요약하면 이렇습니다.

| 단계 | 남은 결론 |
|---|---|
| 시장 규모 | SAM이 TAM의 0.5%. 국내만으로는 천장이 낮음 → SDK/API 형태가 1순위 |
| 페르소나 | 12명으로 넓히고 4명으로 줄였으나 요구는 하나의 1차 제품으로 모임 |
| CJM | 공통 Pain 5개 중 4개는 배치·지연·표현·계측, 5번째는 구조적 배제 |
| 기회점수 | AOS와 DOS 순위가 갈리는 구간을 혼합 매트릭스로 정리 |
| JTBD | 문항지 확정, 모의 응답 12인. 실제 인터뷰 대기 |
