# 08_archive

밀려난 판단을 지우지 않고 옮겨 두는 곳입니다. 왜 틀렸는지가 남아 있으면 같은 실수를 두 번 하지 않습니다.

옮길 때 두 가지를 합니다.

1. 문서의 `status`를 `archived`로 바꿉니다
2. 아래 표에 한 줄 추가합니다

| 날짜 | 문서 | 무엇에 밀렸는가 |
|---|---|---|
|  |  |  |

git 히스토리에 남으니 지워도 된다는 생각은 미룹니다. 히스토리는 **무엇이 바뀌었는지**는 알려 주지만 **왜 밀렸는지**는 알려 주지 않습니다.
