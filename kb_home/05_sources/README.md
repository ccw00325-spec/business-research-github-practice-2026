# 05_sources

숫자가 어디서 왔는지를 한 곳에 모읍니다. 분석 문서마다 출처를 되풀이해 적기보다, 여기 한 번 정리해 두고 `sources` 필드로 가리킵니다.

| 폴더 | 무엇이 들어가는가 |
|---|---|
| [raw/](./raw/) | 원본 파일. PDF·엑셀·캡처 등 그대로 |
| [notes/](./notes/) | 출처별 요약. 인용할 수치와 한계까지 적어 둠 |

## 규칙

원본을 읽고 요약 노트를 만든 다음, 분석 문서는 **요약 노트를 인용**합니다. 원본을 직접 인용하면 매번 다시 열어 봐야 하고, 어느 페이지를 근거로 삼았는지가 남지 않습니다.

노트에는 반드시 두 가지를 적습니다.

- 확정 수치와 추정 수치의 구분
- 이 자료로 답할 수 없는 것 (조사 범위 밖, 시점이 오래됨 등)
