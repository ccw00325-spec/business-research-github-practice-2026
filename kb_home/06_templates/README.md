# 06_templates

새 문서를 만들 때 복사해 씁니다. 프론트매터의 `id`와 `updated`는 반드시 바꿉니다.

| 템플릿 | 쓸 때 |
|---|---|
| [concept.md](./concept.md) | 개념 하나를 정의할 때 |
| [framework.md](./framework.md) | 새 방법론 카드를 만들 때 |
| [case.md](./case.md) | 새 시장·제품 케이스를 열 때 |
| [source-note.md](./source-note.md) | 외부 자료를 읽고 요약할 때 |
| [decision-record.md](./decision-record.md) | 결정을 남길 때 |
| [moc.md](./moc.md) | 새 지도를 만들 때 |

템플릿에 없는 항목을 억지로 채우지 않습니다. 해당 없는 절은 지우는 게 낫습니다 — 빈 제목만 남으면 다음 사람이 아직 안 쓴 건지 해당 없는 건지 알 수 없습니다.
