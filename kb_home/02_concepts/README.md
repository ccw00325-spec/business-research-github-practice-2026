# 02_concepts

개념 하나가 파일 하나입니다. 여러 프레임워크에 걸쳐 반복해 나오는 개념을 여기 한 번만 정의해 두고, 각 문서가 이걸 가리킵니다.

지금은 비어 있습니다. 아래 정도가 먼저 들어올 후보입니다.

- 후방 통합 — 5 Forces와 가치사슬 양쪽에 걸쳐 있습니다
- 중요도 × 충족도 — CJM과 기회점수를 잇는 두 축
- 하향식·상향식 교차 검증 — 시장 규모 추정의 검증 방식
- 구조적 배제 — 감각 채널·지불 능력·기기가 만드는 접근 차단

새 노트는 [concept 템플릿](../06_templates/concept.md)으로 시작합니다. 한 문서에 개념 둘을 담지 않습니다.
