# 용어집

이 저장소 문서에 반복해 나오는 약어와 정의입니다. 정의가 방법론 문서와 어긋나면 방법론 문서가 우선입니다.

| 용어 | 뜻 | 자세히 |
|---|---|---|
| 5 Forces | 산업의 매력도를 다섯 가지 힘으로 판정하는 프레임워크 | [카드](../03_frameworks/porter-five-forces/index.md) |
| 후방 통합 | 공급 측 활동을 직접 떠안아 상류의 교섭력을 줄이는 것 | [카드](../03_frameworks/porter-five-forces/index.md) |
| Value Chain | 기업 활동을 주요활동 5 + 지원활동 4로 갈라 원가·차별화를 진단하는 틀 | [카드](../03_frameworks/value-chain/index.md) |
| KSF | Key Success Factor. 한정된 자원을 먼저 투입할 요인 | [카드](../03_frameworks/ksf/index.md) |
| TAM | 전체 시장 규모 | [카드](../03_frameworks/market-sizing/index.md) |
| SAM | 우리가 실제로 겨냥할 수 있는 부분 시장 | 같은 카드 |
| SOM | 그 안에서 실제로 가져올 몫 | 같은 카드 |
| Market Segment Map | 두 축으로 시장을 나눠 진입 지점을 고르는 지도 | 같은 카드 |
| 페르소나 스펙트럼 | 핵심 사용자에서 극단·비활성까지 넓혔다가 다시 줄이는 5단계 절차 | [카드](../03_frameworks/persona/index.md) |
| CJM | Customer Journey Map. 한 사람이 시간 순으로 겪는 일을 펼친 지도 | [카드](../03_frameworks/cjm/index.md) |
| Pain Point | 여정에서 기대가 꺾이는 지점 | 같은 카드 |
| AOS | 기회점수의 기본형. 중요도와 충족도로 우선순위를 매김 | [카드](../03_frameworks/opportunity-score/index.md) |
| DOS | 시장 가중형 기회점수. AOS에 시장 규모를 곱해 돈의 크기를 반영 | 같은 카드 |
| JTBD | Jobs To Be Done. 사용자가 실제로 해내려는 일을 인터뷰로 확인 | [카드](../03_frameworks/jtbd/index.md) |
| MOC | Map of Content. 원문으로 흩어 보내는 관문 문서 | [지도](../01_maps/) |
