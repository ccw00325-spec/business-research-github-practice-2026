## 두 프레임워크의 관계

```mermaid
flowchart LR
    F["포터의 5가지 힘<br/>산업 <b>밖</b>의 구조"] -->|"여기서 싸울 것인가"| D["전략"]
    V["가치사슬<br/>기업 <b>안</b>의 활동"] -->|"어느 칸부터 손댈 것인가"| D

    classDef out fill:#fdf0d5,stroke:#c1121f,color:#111
    classDef inn fill:#eef3fb,stroke:#4a6fa5,color:#111
    classDef dec fill:#d8f3dc,stroke:#2d6a4f,color:#111
    class F out
    class V inn
    class D dec
```

앞의 질문만 던지면 진단에서 멈추고, 뒤의 질문만 던지면 애초에 이길 수 없는 산업에서 활동만 열심히 개선하게 됩니다. 두 질문을 이어서 던져야 전략이 됩니다.

## Git 연습 메모

이 저장소는 아래 흐름을 익히는 용도로도 씁니다.

- 브랜치 만들고 합치기
- 커밋 되돌리기, 충돌 해결해 보기
- 원격 저장소와 주고받기 (clone / push / pull / fetch)
- Pull Request 흐름 따라가 보기

```bash
git status                 # 현재 상태 보기
git add .                  # 변경분 스테이징
git commit -m "메시지"      # 커밋
git push origin main       # 원격에 반영
git pull origin main       # 원격 변경분 가져오기
```
