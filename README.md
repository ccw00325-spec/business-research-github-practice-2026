# github-prac

Git과 GitHub 사용을 익히기 위한 연습용 저장소입니다.

## 쓰임새

- 브랜치 만들고 합치기
- 커밋 되돌리기, 충돌 해결해 보기
- 원격 저장소와 주고받기 (clone / push / pull / fetch)
- Pull Request 흐름 따라가 보기

## 기본 명령

```bash
git status                 # 현재 상태 보기
git add .                  # 변경분 스테이징
git commit -m "메시지"      # 커밋
git push origin main       # 원격에 반영
git pull origin main       # 원격 변경분 가져오기
```
